# Event Booking System – Software Requirements Specification (SRS)

A comprehensive Software Requirements Specification (SRS) document for a scalable Event Booking System designed to support event discovery, ticket booking, organizer management, reporting, and platform administration workflows.

## Project Overview

This project focuses on analyzing and documenting the functional and non-functional requirements of an event booking platform. The system was designed to support multiple user roles including regular users, event organizers, and administrators.

The SRS defines system behaviors, workflows, use cases, constraints, and platform interactions to ensure clear communication between stakeholders, designers, and developers during the software development lifecycle.

## Features Covered

### User Features
- User registration and authentication
- Event discovery and browsing
- Ticket booking and seat selection
- QR-coded ticket generation
- Booking history tracking
- Event rating and feedback
- Social media event sharing
- Event reminders and notifications

### Event Organizer Features
- Event creation and management
- Ticket management and pricing
- Discount code management
- Sales and attendance reporting
- Revenue statistics generation

### Admin Features
- Organizer verification
- Platform-wide statistics
- User management and moderation
- Event approval and removal

## Documentation Scope

The SRS includes:

- Use cases and workflows
- System actors and permissions
- Preconditions and postconditions
- Exception handling scenarios
- Platform management requirements
